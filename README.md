# final-portfolio

This repository is being constructed so that I can have a final portfolio web application that will be stable, maintainable, usable and long-term.
Previously, I was building a portfolio every year but did not do further to change/improvements every time I did something new (new ranks/projects were not upgraded by me).

Now I hope this will not be the case.

## Compiling the SCSS files

To compile and run the `.scss` files, run the following command:

```
$ npm run scss
```
